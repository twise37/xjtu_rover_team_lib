# 主板代码

本目录用于存放机器人主控板相关代码，包括底层驱动、核心控制逻辑、通信协议和传感器数据处理等内容。

## 主要内容

- 主板初始化与外设配置。
- 电机、舵机、传感器等硬件驱动。
- 运动控制、路径规划和状态机逻辑。
- 与上位机、开发板或其他控制器之间的通信协议。
- 传感器数据融合、滤波和异常处理。

## 推荐目录组织

```text
mainboard/
├── README.md
├── drivers/               # 底层驱动
├── control/               # 控制算法
├── communication/         # 通信协议与数据帧处理
├── sensors/               # 传感器读取与数据处理
└── examples/              # 最小可运行示例
```

## 模块 README 建议包含

- 适用硬件平台与芯片型号。
- 开发环境、编译方式和烧录方式。
- 引脚定义、外设占用和通信波特率。
- 核心接口说明、输入输出单位和异常处理。
- 测试方法、预期现象和已知限制。

## 注意事项

- 修改底层驱动或通信协议时，请同步更新 `docs/` 中的相关说明。
- 涉及硬件安全的代码应写清供电、电流、限位和急停逻辑。
- 控制算法参数建议集中管理，并说明单位和默认值来源。
