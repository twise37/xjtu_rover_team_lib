# 开发文档

本目录用于沉淀团队研发过程中的设计说明、接口定义、开发规范和技术分享。文档应尽量结构化、可复现，并跟随代码和模型一起更新。

## 建议文档分类

| 类型 | 建议文件名 | 内容 |
| --- | --- | --- |
| 架构设计 | `architecture.md` | 系统模块划分、数据流、控制链路 |
| 硬件说明 | `hardware.md` | 主控板、开发板、传感器、电源与接线 |
| 通信协议 | `protocol.md` | 帧格式、字段含义、错误码、示例 |
| 开发规范 | [`code-style.md`](code-style.md) | 命名、格式、目录、注释和提交规范 |
| 调试记录 | `debug-notes.md` | 问题现象、排查过程、解决方案 |

## 写作建议

- 标题尽量具体，避免只写“说明”“记录”等泛化名称。
- 涉及硬件的内容请写清型号、版本、接线和供电条件。
- 涉及接口的内容请写清输入、输出、单位、范围和错误处理。
- 涉及实验结论的内容请补充测试环境、数据来源和复现步骤。

## 贡献方式

新增文档时，请优先使用 Markdown 格式，并在本目录 README 中补充索引。若文档与某个具体模块强相关，也可以放在模块目录下的 `docs/` 子目录中，再从这里添加链接。
