# 开发板代码

本目录用于存放各类开发板的例程代码、功能验证程序与可复用模块。建议将不同开发板或不同实验功能拆分到独立子目录中，方便后续查找和复现。

## 推荐目录组织

```text
development/
├── README.md
├── board-name/
│   ├── README.md          # 开发板说明、接线方式、运行步骤
│   ├── src/               # 源码
│   └── docs/              # 该开发板相关补充文档
└── experiments/
    └── feature-name/      # 临时实验或验证代码
```

## README 建议包含

- 开发板型号、主控芯片和外设资源。
- 开发环境、工具链版本和烧录方式。
- 接线说明、供电注意事项和调试串口配置。
- 例程功能、运行步骤和预期现象。
- 已知问题、限制条件和后续计划。

## 提交注意事项

- 请不要提交 IDE 缓存、编译输出、临时日志和本地配置文件。
- 实验代码请标注验证状态，避免被误认为稳定模块。
- 若例程依赖主板代码或文档，请在 README 中写明引用路径。
